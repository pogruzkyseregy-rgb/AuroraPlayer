# fluorite_blue: музыкальный плеер с Авророй для Android

Плеер для mp3 и других аудиофайлов с телефона. Над горизонтом встаёт солнце
с лисьими ушками: оно поднимается по мере проигрывания трека, а эквалайзер
расходится от него лучами. Музыка играет в фоне и при выключенном экране,
есть уведомление с кнопками и управление с экрана блокировки и из наушников.

Требуется Android 8.0 или новее.

## Как собрать APK

### Вариант 1. Android Studio (удобнее всего дорабатывать)
1. Установи Android Studio: https://developer.android.com/studio
2. File → Open → выбери папку `AuroraPlayer`.
3. Подожди, пока внизу закончится синхронизация Gradle (первый раз долго, качает зависимости).
4. Подключи телефон по USB с включённой «Отладкой по USB» и нажми зелёный ▶ Run.
   Или: Build → Build App Bundle(s) / APK(s) → Build APK(s), файл появится в
   `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант 2. GitHub (без Android Studio, можно даже с телефона)
1. Создай репозиторий на GitHub и загрузи туда содержимое папки `AuroraPlayer`
   (вместе со скрытой папкой `.github`).
2. Открой вкладку Actions: сборка «Собрать APK» запустится сама после загрузки.
3. Когда она станет зелёной, открой её и скачай архив `aurora-player-apk`
   внизу страницы. Внутри лежит APK, его можно ставить на телефон.

Каждая новая загрузка изменений в репозиторий пересобирает APK.

## Что где лежит

| Файл | Что внутри |
|---|---|
| `app/src/main/assets/www/index.html` | Весь интерфейс: цвета, кнопки, небо, вкладки, плейлисты, окна таймера и эквалайзера, реплики Авроры. |
| `app/src/main/assets/www/bg.png`, `av-logo.png` | Фон с лапками и логотип AV в подписи внизу. |
| `app/src/main/assets/www/aurora.jpg` | Арт Авроры (аватар в шапке и картинка на весь экран). Замени файл, чтобы поменять арт. |
| `.../player/MainActivity.kt` | Главный экран: связывает интерфейс с плеером, ищет музыку, хранит плейлисты. |
| `.../player/PlaybackService.kt` | Проигрывание в фоне, таймер сна, эквалайзер. |
| `.../player/Library.kt` | Поиск музыки на телефоне, плейлисты, очередь, твои правки названий и обложек (`Custom`), статистика прослушиваний (`Stats`). |
| `.../player/AuroraWidget.kt` | Виджет на рабочий стол. Внешний вид: `res/layout/widget.xml`. |
| `.../player/Spectrum.kt` | Лучи-эквалайзер на небе. |
| `app/aurora-debug.jks` | Ключ подписи. Не удаляй, иначе обновления не встанут поверх старой версии. |

## Частые доработки

**Радио.** Станции берутся из открытого каталога Radio Browser (radio-browser.info),
поиск в `MainActivity.kt` (`radioSearch`), интерфейс вкладки в `index.html` (`radioHtml`).
Жанры для кнопок лежат в `GENRES`.

**Фон и эквалайзер.** Выбираются отдельно и сочетаются друг с другом. Фоны — в `BGS`,
рисуют функции `drawBg<Имя>`. Эквалайзеры — в `EQS`, рисуют функции `eq<Имя>` и всегда
накладываются поверх уже нарисованного фона. Новый фон или эквалайзер — это новая
функция и одна строчка в соответствующем списке в `index.html`.

**Рекомендации Авроры.** Считаются в `index.html`, функция `recsHtml()`. Чтобы добавить
подборку, допиши ещё один блок `secs.push(...)`. Трек засчитывается как прослушанный,
когда дослушан до середины (не дольше 30 секунд), это правило в `PlaybackService.kt` (`statFlush`).

**Имя в подписи внизу.** В `index.html` строка `const USER_NAME="Adonis";`.

**Добавить реплики Авроры.** В `index.html` найди блок «Реплики Авроры» и допиши
строки в нужный список (`play`, `pause` и т.д.).

**Поменять цвета.** В `index.html` в самом верху блок `:root`. Цвет неба на
рассвете задаётся в функции `draw()` (строки с `mix('#...','#...',p)`).

**Лучи отстают от музыки или опережают её.** В `Spectrum.kt` поменяй `LATENCY_MS`.

**Новая кнопка, которой нужен плеер.** Добавь метод с `@JavascriptInterface`
в класс `Bridge` в `MainActivity.kt`, и вызывай его из страницы как `Android.имяМетода()`.
Чтобы отправить что-то из Kotlin на страницу, используй `js("fromAndroid.что_то(...)")`
и добавь такую функцию в объект `window.fromAndroid` в `index.html`.

**Чат с Авророй.** Интерфейс это обычная веб-страница, так что можно сделать
запрос к своему серверу через `fetch()`, как на сайте (разрешение на интернет
уже есть в `AndroidManifest.xml`).

## Что стоит знать

- Шрифты грузятся из интернета. Без сети будут системные, всё остальное работает.
  Чтобы работало офлайн, положи файлы шрифтов в `assets/www` и подключи через `@font-face`.
- Музыку приложение находит через медиатеку Android. Если только что
  скачанный трек не появился, нажми ⟳ рядом с поиском.
- При каждом изменении не забывай увеличить `versionCode` в `app/build.gradle.kts`.
- Название и исполнитель берутся из тегов. В очень старых mp3 с тегами
  в кодировке Windows-1251 могут появиться «кракозябры».
- Версии библиотек указаны в `app/build.gradle.kts`. Если Android Studio
  предложит их обновить, можно соглашаться, но после обновления проверь сборку.


## Версия 3.0 — новое

- **Повтор трека/очереди теперь запоминается насовсем** (раньше слетал при перезапуске телефона).
  Хранится в `SharedPreferences` ("aurora"/"repeat"), сохраняется в `MainActivity.setRepeat`,
  восстанавливается в `PlaybackService.onCreate`.
- **Режим «Тишина».** Если музыка на паузе (или ничего не играет) и телефон не трогали
  25 секунд — экран плавно гаснет в тёмно-фиолетовый с мигающей строкой `> система запущена`.
  Гаснет обратно от любого касания ИЛИ если музыка сама возобновилась (виджет/наушники).
  Всё в `index.html`: `#idleScreen`, `setIdle()`, таймер в `IDLE_AFTER_MS`.
- **Глитчи при белом шуме/помехах.** Если спектр трека похож на шум (плоская «спектральная
  плоскостность» по всем полосам, не басовый профиль обычной музыки) — экран периодически
  волнами сбоит: полосы со сдвигом и цветной каёмкой, цифровой шум, мерцание Авроры.
  Логика в `index.html`: `updateNoise()`, `tickGlitch()`, `drawGlitch()`. Чистая эвристика
  по данным того же эквалайзера, без новых зависимостей.


## Версия 3.1 — исправление

- **Починен баг**: кнопка «Перемешать» после прослушивания маленького плейлиста/подборки
  зацикливалась на нескольких треках вместо всей библиотеки. Причина была в том, что
  «Перемешать» при уже играющем треке мешала внутри текущей очереди (`shufflePlay()` в
  `MainActivity.kt`), а не всей библиотеки. Теперь кнопка всегда берёт случайный трек из
  всей библиотеки, независимо от того, что играло до этого. Функция `shufflePlay()` в
  Kotlin удалена как больше не используемая.

## Версия 3.5 — настоящее исправление перемешивания

Прошлый фикс (3.1) убрал зацикливание на маленькой очереди, но не до конца: кнопка
«Перемешать» слала id всей библиотеки в ОДНОМ и том же порядке каждый раз, меняя только
стартовый индекс. На Kotlin-стороне (`playQueue` в `MainActivity.kt`) есть оптимизация —
если новая очередь совпадает с уже загруженной (тот же источник, то же количество, тот же
порядок id), плеер не пересобирает её, а просто переходит на нужный индекс. Из-за этого
реальный порядок для кнопки «дальше» вычислялся один-единственный раз и дальше не менялся,
сколько кнопку ни нажимай — отсюда ощущение, что плеер крутится по кругу.

Теперь JS сам перемешивает порядок id (Fisher–Yates) перед отправкой и всегда стартует
с индекса 0 — порядок каждый раз гарантированно другой, значит Kotlin-сторона больше не
принимает это за «ту же очередь» и пересобирает плеер по-настоящему. Проверено: шесть
нажатий подряд — шесть разных порядков.
