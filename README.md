# Аврора: музыкальный плеер для Android

Плеер для mp3 и других аудиофайлов с телефона. Над горизонтом встаёт солнце
с лисьими ушками: оно поднимается по мере проигрывания трека, а эквалайзер
расходится от него лучами. Музыка играет в фоне и при выключенном экране,
есть уведомление с кнопками и управление с экрана блокировки и из наушников.

Требуется Android 8.0 или новее.

## Как собрать APK

### Вариант 1. Android Studio (удобнее всего дорабатывать)
1. Установи Android Studio: https://developer.android.com/studio
2. File → Open → выбери папку `AuroraPlayer`.
3. Подожди, пока внизу закончится синхронизация Gradle (первый раз долго, качает зависимости).
4. Подключи телефон по USB с включённой «Отладкой по USB» и нажми зелёный ▶ Run.
   Или: Build → Build App Bundle(s) / APK(s) → Build APK(s), файл появится в
   `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант 2. GitHub (без Android Studio, можно даже с телефона)
1. Создай репозиторий на GitHub и загрузи туда содержимое папки `AuroraPlayer`
   (вместе со скрытой папкой `.github`).
2. Открой вкладку Actions: сборка «Собрать APK» запустится сама после загрузки.
3. Когда она станет зелёной, открой её и скачай архив `aurora-player-apk`
   внизу страницы. Внутри лежит APK, его можно ставить на телефон.

Каждая новая загрузка изменений в репозиторий пересобирает APK.

## Что где лежит

| Файл | Что внутри |
|---|---|
| `app/src/main/assets/www/index.html` | Весь интерфейс: цвета, кнопки, небо, реплики Авроры. Обычный HTML/CSS/JS. |
| `.../player/MainActivity.kt` | Главный экран. Связывает интерфейс с плеером, открывает выбор файлов. |
| `.../player/PlaybackService.kt` | Сервис проигрывания (ExoPlayer). Фон, уведомление, наушники, звонки. |
| `.../player/Spectrum.kt` | Эквалайзер: раскладывает звук на 22 полосы для лучей. |
| `.../player/TrackStore.kt` | Плейлист: сохранение, теги, обложки. |
| `app/src/main/res/drawable/ic_launcher_*.xml` | Иконка приложения. |
| `app/src/main/res/values/strings.xml` | Название приложения. |

## Частые доработки

**Добавить реплики Авроры.** В `index.html` найди блок «Реплики Авроры» и допиши
строки в нужный список (`play`, `pause` и т.д.).

**Поменять цвета.** В `index.html` в самом верху блок `:root`. Цвет неба на
рассвете задаётся в функции `draw()` (строки с `mix('#...','#...',p)`).

**Лучи отстают от музыки или опережают её.** В `Spectrum.kt` поменяй `LATENCY_MS`.

**Новая кнопка, которой нужен плеер.** Добавь метод с `@JavascriptInterface`
в класс `Bridge` в `MainActivity.kt`, и вызывай его из страницы как `Android.имяМетода()`.
Чтобы отправить что-то из Kotlin на страницу, используй `js("fromAndroid.что_то(...)")`
и добавь такую функцию в объект `window.fromAndroid` в `index.html`.

**Чат с Авророй.** Интерфейс это обычная веб-страница, так что можно сделать
запрос к своему серверу через `fetch()`, как на сайте (разрешение на интернет
уже есть в `AndroidManifest.xml`).

## Что стоит знать

- Шрифты грузятся из интернета. Без сети будут системные, всё остальное работает.
  Чтобы работало офлайн, положи файлы шрифтов в `assets/www` и подключи через `@font-face`.
- Файлы не копируются в приложение, запоминается только ссылка на них.
  Если удалить или переместить песню на телефоне, она перестанет играть:
  убери её из плейлиста и добавь заново.
- Название и исполнитель берутся из тегов. В очень старых mp3 с тегами
  в кодировке Windows-1251 могут появиться «кракозябры».
- Версии библиотек указаны в `app/build.gradle.kts`. Если Android Studio
  предложит их обновить, можно соглашаться, но после обновления проверь сборку.
